# 人眼验证清单

自动化回归（`run-all.js`）证明的是**逻辑与数值**。它证明不了：
新 UI 画出来是什么样、窄屏会不会挤、辅助线看起来顺不顺眼、打起来手感如何。
那些只能人眼看、只能人玩。

这份清单是给「打开游戏 → 照着做 → 记录结论」用的。

---

## 快速开始

```bash
# 直接双击 index.html，或：
python -m http.server 8000     # 然后开 http://localhost:8000
```

进入游戏后：右上角 **⚙ 设置** → **瞄准辅助线** 选 **弹道预览**。
（`?` 键打开的「玩法说明」面板里有同一组按钮，两处共用同一个设置。）

## 一、先分清三个容易搞混的标记

辅助线开着的时候，屏幕上同时有这几种东西，从外到内：

| 标记 | 长什么样 | 位置 | 说明 |
|---|---|---|---|
| **力度环** | 半圆环，绿→黄→红 | **套在球周围**，半径 36px | 蓄力条。**三个档位都在画**，跟辅助线设置无关 |
| **拉杆** | 橙色虚线 + 橙点 | 球 → 你的手指 | 拖拽方向与长度 |
| **出手点** | 黄色小点 | 球上方偏右，起跳最高点处 | 球真正脱手的位置（比球现在高 96px） |
| **路径点** | 一串圆点，白色渐隐 | 空中 | **碰到篮圈/篮板之后转琥珀色** |
| **绿圈** | 小圆圈，亮绿，半径 13px | **球预测穿过篮圈的那个点** | ✅ 这一杆能进 |
| **橙圈 + 叉** | 小圆圈 + 一个 ×，橙色，半径 9px | 同上 | ❌ 会打铁 |
| **虚影** | 虚线横杆 + 两端短竖线 | 篮圈所在高度 | 球到达那一刻**移动篮架会在哪** |

> ⚠️ **「绿圈」不是力度环**。力度环是套在球身上的大圆环，绿圈是落在篮圈位置的小圆圈。
> 刚做这个功能时我自己也在这里绕了一圈。

**虚影的三个出现条件**（同时满足）：关卡有移动篮架 **且** 模拟算出了命中时刻
**且** 命中时刻 < 1.6 秒。超时宁可不画，也不给一个看起来很确定的错误结果。

- L1 / L2 / L4 是**静止篮架 → 永远没有虚影**，这是正常的
- 虚影位置与实线篮圈**不重合是正常的** —— 那个偏移量正是提前量
- 虚影是**绿色** = 预测能进；**灰色** = 预测偏差太大，进不去

## 二、P2-7 验证：绿圈亮了就必须真得分

### 为什么只有两关能验证

2026-10-11 修掉了一个预览 bug：`RELEASE_DELAY` 比实机实际出手时刻少 0.8 帧（32.2 vs 33），
篮架每帧最多移 1.6px，合 1.3px 的系统偏差。后果：

| 关 | 篮架 | 修前表现 |
|---|---|---|
| L1 / L2 / L4 | 静止 | 无影响 |
| L6 / L8 | x 轴移动 | 误差从 0.01px 抬到 0.22px，**照样进**，看不出区别 |
| **L3 / L7** | **y 轴移动** | 绿圈照样亮，松手**打铁** |

所以**只有 L3 和 L7 能验证出差别**。自动化测试已确认修后闭环 8/8 全通
（见 `02-physics.js` C 节），这里只做人眼的最终确认。

### 怎么做

1. 进入 **L3**（第 3 关，提示「篮架上下移动，注意提前量」）
2. 辅助线 = **弹道预览**
3. 拖拽到**篮圈高度接近球弧线顶点**的那一杆
   —— 也就是球飞到最高点附近、篮架也正好在那个高度时
4. 盯住绿圈，然后**松手**

### 判定

| 现象 | 结论 |
|---|---|
| 绿圈亮 → 球真的穿过篮圈、**加分** | ✅ 修好了 |
| 绿圈亮 → **打铁** | ❌ 还有残留偏差，请截图记录角度 / 力度 / 第几关 |

**别用虚影对不对齐来判断**。修前修后虚影只差约 1.3px，肉眼根本看不出差别 ——
这次修的是「判定有没有翻转」，不是「虚影对齐了几 px」。
**唯一有效的判据是「绿圈 → 实际得分」这个闭环。**

## 三、还没验证过的（自动化测不到）

### 3.1 新 UI 排版 —— 优先级最高

新加了三处横向占位：**HUD 的生命胶囊**、**开局卡片的模式分段控件**、**结算卡片的那一套**。

P1-1 已经记录「视口 ≤560px 时整页横向溢出」。这三处叠加很可能更糟。

- [ ] 桌面宽度下，三处排版正常、无重叠
- [ ] 结算卡片：标题 / 分数 / 星级 / 说明 / 历史行 / 模式分段 / 按钮，7 块内容不挤
- [ ] 把窗口拖到 **375px 宽**，看 HUD 有没有横向溢出或被裁掉
- [ ] 切到 ♾ 无尽，确认 HUD 出现 `❤❤❤`；剩 1 颗时变成 `❤♡♡` 且转成告警色
- [ ] 战役模式下生命胶囊是**隐藏**的（不是显示 3 颗假心）

### 3.2 三种模式的实际手感

自动化只用机器人证明了「`par` 没有定到打不动」（机器人撑到第 15 波、达标平均 2.9 球），
证明不了好不好玩。

- [ ] 无尽连打 20 波，疲劳感如何？`par` 涨得慢（40 波只 +43）会不会觉得没劲？
- [ ] 每日挑战作为每天一次的例行，会不会觉得烦 / 没新鲜感？
- [ ] 连胜断档归零（失败当天立刻清零）是不是太狠？

### 3.3 超长会话与边界

- [ ] 无尽模式连续玩 1 小时以上有没有异常（`g.lv.timer` 不回绕，靠推算没实测）
- [ ] 每日挑战跨零点开的一局（23:59 开、00:01 完）记到哪一天，行为是否符合预期
- [ ] 刷新页面 / 隐身窗口 / 存储配额满，各模式下游戏是否照常可玩
